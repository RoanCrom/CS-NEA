This is my computer science NEA project for my A level computer science NEA via the AQA exam board at hills road sixth form.

This is a app that will allow you to study either A level or GCSE theory for computer science a weight based learning system to ensure you get questions correct and consistent.

The scripts have all been hand written by me with the help of stack exchange forum posts for thing I do not know.

Main.py - Where the question logic is stored and sends information to the GUI
GUI.py - The GUI for the program and links to the question logic
Questions.json - Question bank of 30 questions and answers
